How to use it

01

Browse & cycle

Open any style and flip through the entire filtered set with the ← → arrow keys. Every card shows the real palette, typography and tags.

02

Filter anything

Sidebar filters for category, project, dark/light, hue family, tags and status (candidate / final / rejected / shipped). Or search with /.

03

Ask the Concierge

The ✦ chatbot runs on a local model and knows the whole catalog — “dark + gold for a law firm” narrows the gallery live.

04

Star your picks

Press S to shortlist. Picks persist with notes — the shortlist for any new project.

05

Reference by code

Every style has a stable code like TZ-007 or HL-E11 — cite it in any conversation, agent task or ticket and it means exactly one style.

06

Grow it forever

New project? Drop a findings JSON (schema in AGENTS.md) and run scripts/update_catalog.py — the Atlas absorbs it idempotently.
